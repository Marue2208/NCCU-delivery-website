how to publish it

The easiest free option is Netlify Drop. It takes about two minutes and needs no coding.

  1. Download the file. Save index.html from the file pane to your computer. The file name has to stay index.html.
  2. Put it in a folder. Create a new folder and put index.html inside it.
  3. Upload it. Go to app.netlify.com/drop, sign up for free, and drag the folder onto the page.
  4. Get your link. Netlify gives you a public address right away, something like random-name.netlify.app.
  5. Rename the link. In Site settings, choose "Change site name" and pick something like nccu-delivery. Your link becomes nccu-delivery.netlify.app.
  6. Share it. Put the link in your LINE and Instagram bios and test it on your phone.

To update the site later, drag the new folder onto the same site in Netlify's "Deploys" tab.

Other free options. GitHub Pages and Cloudflare Pages work the same way. They're better if you plan to keep editing the site often.

Custom domain. A domain like nccudelivery.com costs about NT$400–600 a year. You can add it in Netlify later.
